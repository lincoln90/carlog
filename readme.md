# CarLog - 愛車メンテナンス記録

愛車のメンテナンス履歴、車検証情報、オイル交換時期などをブラウザ上で手軽に管理できるシングルページ Web アプリケーションです。

## 主な機能

- **複数車両の管理**: 車両の基本情報を登録し、車両ごとの切り替えや全体表示に対応
- **メンテナンス記録**: 整備・点検などの履歴の登録・編集・削除
- **オイル交換アラート**: 設定した交換サイクル（デフォルト180日）に応じたリマインダー表示・通知機能
- **車検証情報の管理**: 最新の車検証情報の表示および更新履歴の管理
- **Googleスプレッドシート連携**: Google Apps Script (GAS) の Web アプリ URL を設定することで、スプレッドシートとのデータ連携が可能
- **ローカル保存 & PWA対応**: ブラウザの `localStorage` によるデータ保持、および動的マニフェストによるホーム画面追加（PWA）に対応

## 使い方

1. `app.html` をブラウザで開きます。
2. 必要に応じて「新しい車を追加」から車両情報を登録します。
3. メンテナンス記録や車検証情報を登録・管理します。
4. （任意）Googleスプレッドシートと連携する場合は、設定画面から GAS の Web アプリ URL を登録してください。
